# 网申助手 Apply Assistant

用于 Edge 和 Chrome 的本地浏览器扩展。管理多个简历版本，在网申表单中匹配并填写个人信息、教育、实习、项目和自定义经历。当前版本：0.6.24。

## 功能

- 可视化资料面板，支持创建、复制、切换和导入导出多个投递版本。
- 个人信息、教育经历、实习经历、项目经历，以及可自定义的校园、获奖、语言、家庭等资料模块。
- 整页匹配预览、一键填写空白字段，按明确的学校、公司、项目或职务名称对应多段经历。
- 自动添加缺少的经历区块；遇到未知记录、重名或多个添加入口时保留待核对。
- 支持部分下拉、搜索候选、年月日历和“至今”控件；已有文本差异由用户明确选择更新。
- 普通文本和原生下拉可撤销本次填入，保留后续手动编辑。

## 安装

1. 从 [Releases](https://github.com/Cccoan1120/apply-assistant/releases) 下载通用 ZIP 并解压，或克隆本仓库。
2. Edge 打开 `edge://extensions`，Chrome 打开 `chrome://extensions`，开启“开发人员模式”。
3. 选择“加载解压缩的扩展程序”，选中解压后或仓库中的 `extension` 文件夹。
4. 在招聘网页点击右下角的“网申助手”，或点击浏览器工具栏中的扩展图标打开侧栏。
5. 打开资料面板，录入自己的信息并保存。首次安装从空白版本开始，也可导入自己导出的资料文件。

升级时重新加载原扩展，再刷新招聘网页，无需卸载或重新导入资料。Edge 和 Chrome 的资料分别保存。

## 使用

1. 在资料面板准备版本，可按目标岗位复制、修改，也可增减资料模块和字段。
2. 进入网申编辑页，在侧栏选择版本，点击“预览整页匹配”或“一键填写当前页”。
3. 核对匹配结果和网页回显。已有实习或项目的正文需要更新时，使用“按当前模板更新差异”。
4. 最后由自己保存、进入下一步或提交。插件不会点击这些操作。

没有单独“实习经历”区块、且未配置明确的工作经历模板时，页面的“工作经历”可借用实习资料，保留实习岗位名称。存在独立实习区块或明确工作模板时分别处理。

## 适配范围

优先支持北森、Moka、飞书招聘及 Hotjob 的常见表单，包括原生输入和下拉、部分 Phoenix、Universe Design、ATSX、Ant Design 和 Moka 控件。通过标签、区块结构和唯一候选匹配，不调用模型改写简历。

常见平台域名自动显示入口；京东方、海康、德邦、立白的已配置独立域名也有自动入口。其他独立域名可先从浏览器工具栏打开扩展，再识别当前页。

无法保证每家企业的定制页面均可填写。复杂级联、多选、富文本、关闭的 Shadow DOM、跨域 iframe 或缺少唯一候选的控件可能需要手动处理。表单尚未加载时会短暂等待重扫。具体日期缺失时请核对匹配结果。

## 资料与权限

- 资料保存在当前浏览器的 `chrome.storage.local`。扩展没有云端同步、资料上传接口或模型调用。
- 扩展使用 `activeTab`、`scripting`、`storage`、`sidePanel` 及已列明的招聘域名权限。完整范围见 [manifest.json](extension/manifest.json)。
- 点击填写会把所选资料写入当前招聘网页；网站本身可能自动保存。已有值默认保留，协议、密码和验证码不会自动填写或选择。
- 本仓库和通用安装包不含个人简历、私有预设、浏览器登录状态或资料导出文件。请勿把自己的资料备份提交到 Git。

## 开发与验证

需要 Node.js 24、npm；生成 ZIP 的脚本使用 PowerShell。

```powershell
npm ci
npx playwright install chromium
npm test
npm run test:browser
npm run test:launcher
npm run test:dashboard
npm run package
```

`extension` 可直接加载，无需构建。`node scripts/assets.mjs` 可重新生成扩展图标并复制本地 Lucide 资源。通用 ZIP 生成于 `dist`，个人预设不会被打包。

`npm run preview` 启动可选的本地资料面板预览，地址为 `http://127.0.0.1:4178/dashboard.html`；正式扩展无需服务器。网页预览使用独立本地存储，与扩展资料不自动同步。

单元测试使用虚构资料、构造控件和脱敏的表单结构。浏览器测试在隔离环境中验证侧栏、存储、入口、填写和撤销，不提交真实网申。少数额外控件实验脚本依赖未发布的网站公开资源缓存，不属于上述标准验证命令。测试通过不代表所有招聘网站均已实测。

报告兼容问题时，可在 [Issues](https://github.com/Cccoan1120/apply-assistant/issues) 提供平台、浏览器版本、字段名称和脱敏截图；分享链接前请移除 `userId`、`resumeId`、`share_token` 等个人参数。
